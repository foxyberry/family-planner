# M2 sizing formulas: every landscape iPad

**Status (2026-11-09): done** in PR #15 (steps 1–7, 9); step 8 (grown-up part spacing) moves to the layout plan `2026-11-09-m2-layout-and-next.md`. BoardFrame is removed.

Spec: `docs/superpowers/specs/2026-11-07-m2-screens-spec.md`, Shared rules › Grid and frame ›
"Sizing formulas". Branch `feature/m2-sizing` (from `feature/m2-principles`, PR #14).

Goal: replace the whole-board `scaleEffect` (`BoardFrame`) with per-value sizing, so text stays
crisp, hit areas stay true and floors hold on the mini. At 13" every value equals the board.

## Steps

1. **`Sizing` value** (DesignSystem/Tokens): inputs W, H, safe.top; `s = min(W/1376, (H − safe.top)/1008)`
   (floored at 0.70); `fluid(ref, lo)`; `y(board)` = safe.top + (y − 24)·s; `left(x)`, `right(x)`,
   `stretch` (64s … W − 64s); grid margin/gutter/column. Unit tests for the five iPads in the spec.
2. **Environment**: `\.sizing` (default = 13"), set once at the app root from a full-screen
   GeometryReader (size + safe-area top). Gallery and snapshots set it explicitly.
3. **Type**: `crayonType` reads `\.sizing`: hero `fluid(144, 96)`, display `fluid(96, 64)`, title
   `fluid(48, 36)`, head `fluid(36, 30)`, body `fluid(30, 24)`, caption 24 fixed;
   `Font.custom(name, size:, relativeTo:)`. Display box height follows its size.
4. **Spacing**: `Spacing` stays the board token; add `sizing.space(_:)` (4/8/12 fixed, 16/24/40/64
   fluid). Screens and frames switch to it first; parts after (step 8).
5. **Kid frames**: `KidFullScreen`/`KidScreen` lay out full-screen without `scaleEffect`; screens
   place regions with `sizing.y`, anchors and stretch.
6. **Home**: clock R 372s, centre (448s, safe.top + 504s) — `PieClock` takes a scale for its
   geometry; sky switch at (40s, y(36)); right panel stretches 928s … W − 64s, y(96) … y(968).
7. **A2-MVP**: header y(48)…y(128), strip y(176) height 340s (x × width/1248), kids and missions
   y(536)…y(968); mission circle 112s; tap targets ≥ 64.
8. **Grown-up frame and parts**: `GrownupScreen` margin/gutter/header from `Sizing`; part spacing.
9. **Checks**: snapshot/pixel tests at 1376×1032, 1366×1024, 1180×820, 1133×744 — band empty,
   no text under its floor, kid tap targets ≥ 64. Run on a mini simulator once.
10. Remove `BoardFrame`; spec copy check; `make test`; iPad check.
